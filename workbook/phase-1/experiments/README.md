# Phase 1 관찰 실험

읽고 고개를 끄덕이는 것과, **같은 코드가 조건에 따라 다르게 출력되는 것을 화면에서 보는 것**은 다른 일이다.
튜토리얼 [phase-1.md](../../../docs/tutorial/phase-1.md)의 "손으로 확인하기"를 실행 가능한 파일로 옮겨 놓고,
숫자를 직접 세게 만들었다.

**전부 저장소 루트에서 실행한다.** 서로 의존하지 않는다.

```
uv run python workbook/phase-1/experiments/01_hash_avalanche.py
uv run python workbook/phase-1/experiments/02_json_bytes.py
uv run python workbook/phase-1/experiments/03_block_hash_probe.py
```

| 스크립트 | 무엇을 보여주나 | 언제 돌리나 |
|---|---|---|
| [`01_hash_avalanche.py`](01_hash_avalanche.py) | 같은 입력 1000번의 결과가 **한 종류**인 것. 한 글자만 바꿨을 때 256비트 중 **몇 개가 뒤집히는지 숫자로**. 입력이 1바이트든 1MB든 출력이 64자인 것. 앞자리 0 을 하나 더 요구할 때마다 시도가 **16배**로 뛰는 표 | [Lab 1.1](../lab-1.1.md) |
| [`02_json_bytes.py`](02_json_bytes.py) | 논리적으로 같은 글 하나가 **12가지 바이트열**이 되는 것. 무엇을 고정하면 그게 1가지로 모이는지. 그리고 고정해도 안 잡히는 것 — tuple이 list가 되고 int 키가 문자열이 되는 **조용한 변환** | [Lab 1.1](../lab-1.1.md), [Lab 1.5](../lab-1.5.md) |
| [`03_block_hash_probe.py`](03_block_hash_probe.py) | **네가 만든 `Block`을 불러다 찔러 본다.** 필드를 하나씩 바꿔 보며 어느 필드가 해시에 반영되는지. 블록 세 개를 이어 붙이고 맨 앞을 고쳤을 때 뒤가 어떻게 되는지 | [Lab 1.3](../lab-1.3.md) 과제를 한 **뒤**, [Lab 1.4](../lab-1.4.md) **뒤에 한 번 더** |

## `03`은 두 번 돌려라

이 실험은 **같은 명령인데 Lab 1.3 직후와 Lab 1.4 직후의 출력이 다르다.** 그 차이가 이 실험의 핵심이다.

| 돌리는 시점 | 마지막 줄 `txs (글 본문)` | 무슨 뜻인가 |
|---|---|---|
| Lab 1.3 직후 | 바뀐다 | 글이 해시 입력에 **직접** 들어 있다 |
| Lab 1.4 직후 | 그대로 | 글을 커밋하는 경로가 `merkle_root`로 **옮겨 갔다** |

두 번째 출력을 보고 놀라지 마라. 그게 Lab 1.4가 시킨 교체다.
다만 그 순간부터 `validate()`가 `merkle_root`를 `txs`로부터 재계산해 대조하지 않으면
**본문 변조가 아무 데서도 안 잡힌다.** 실험이 그 경고를 직접 출력한다.

## 구현이 아직 없으면

`03`은 `src/bbschain/core/block.py`를 불러 쓴다. 없으면 이런 안내를 내고 조용히 끝난다.

```

 아직 여기까지 못 왔다 (이 시점에서는 정상이다)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**에러가 아니다.** 먼저 돌려 봐도 손해가 없다. `01`과 `02`는 구현과 무관하게 언제나 돈다.

## 읽는 법

각 출력에는 `👀 볼 것:` 줄이 붙어 있다. **숫자나 목록보다 그 줄이 본체다.**

- 돌리기 **전에** 결과를 예상해 봐라. 예상과 다른 지점이 이 실험의 수확이다.
- 예상과 달랐던 것은 워크북 시트의 `📝` 칸이나 [`notes/`](../../notes/)에 적는다.

## 주의

- 🔴 **이 스크립트들은 랩 과제의 답이 아니다.**
  `01`과 `02`에는 `bbschain` 코드가 한 줄도 없다. `hashlib`과 `json`만 쓴다.
  `03`은 **네 구현을 불러다 관찰할 뿐**이고, 정규 직렬화도 머클 루트도 여기서 계산하지 않는다.
- 파일을 만들지 않는다. 저장소를 더럽히지 않는다.
- `01`의 (D)는 20만 번 해시한다. 몇 초 걸린다.

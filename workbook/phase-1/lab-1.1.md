## 1. 먼저 깨져보기 ⚔

**보려는 것**: 논리적으로 **완전히 같은 글**인데 해시가 달라지는 것.

`labs/hash_play.py`에 써도 되고, 아래를 그대로 터미널에 붙여 넣어도 된다.

### ① 같은 문자열을 여러 번 해시한다

```
uv run python -c "
import hashlib
print({hashlib.sha256('hello'.encode()).hexdigest() for _ in range(100)})
"
```

```
{'2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824'}
```

- [ ] 100번 돌렸는데 결과가 **한 개**다

### ② 끝에 공백 하나만 붙인다

```
uv run python -c "
import hashlib
for s in ['hello', 'hello ']:
    print(repr(s), hashlib.sha256(s.encode()).hexdigest())
"
```

```
'hello' 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
'hello ' 5e3235a8346e5a4585f8c58562f5052b8fe26a3bb122e1e96c76784964dfc461
```

> **두 값 다 네 화면과 글자까지 같아야 한다.** 해시는 컴퓨터가 달라도 같은 값을 낸다.
> 다르면 붙여 넣을 때 뭔가 빠진 것이다.

- [ ] 한 글자 차이인데 **비슷한 구석이 없다**

### ③ 키 순서만 다른 두 딕셔너리 ← ★ 여기가 핵심이다

```
uv run python -c "
import hashlib, json
a = {'author': 'sam', 'body': 'hello'}
b = {'body': 'hello', 'author': 'sam'}
print(a == b)
for x in (a, b):
    print(json.dumps(x), hashlib.sha256(json.dumps(x).encode()).hexdigest()[:16])
"
```

```
True
{"author": "sam", "body": "hello"} 63dc015a3da165a9
{"body": "hello", "author": "sam"} fbb2058456d8777b
```

- [ ] 파이썬은 **같다(True)** 고 하는데 해시는 **다르다**

### ④ 들여쓰기만 다르게

```
uv run python -c "
import hashlib, json
a = {'author': 'sam', 'body': 'hello'}
for kw in ({}, {'indent': 2}):
    print(hashlib.sha256(json.dumps(a, **kw).encode()).hexdigest()[:16], kw)
"
```

```
63dc015a3da165a9 {}
97d4c41263b12595 {'indent': 2}
```

- [ ] 다르다

### ⑤ 인코딩만 다르게

```
uv run python -c "
import hashlib
s = '오늘 점심'
for enc in ('utf-8', 'utf-16'):
    print(enc, hashlib.sha256(s.encode(enc)).hexdigest()[:16])
"
```

```
utf-8 39e2da3abe542a5e
utf-16 06ec374756ab0dc5
```

- [ ] 다르다

**③④⑤가 이 랩의 전부다. 내용은 같은데 해시가 다르다.**

이게 블록체인에서 일어나면 어떻게 되나. 내 노드는 블록을 A 방식으로 직렬화해 해시하고,
네 노드는 B 방식으로 한다. 같은 블록인데 해시가 다르다.
**두 노드는 영원히 합의하지 못한다.**

## 4. 코드를 어떤 순서로 쓰나

이 랩의 산출물은 **코드가 아니라 메모**다. 그래도 순서는 있다.

**1단계 — 무엇이 이걸 판정하는지 확인한다.**
이 랩에는 pytest가 없다. **판정기는 네 눈이다.**
목표는 하나다. "키 순서만 바꿨는데 해시가 달라지는 화면"을 직접 본다.

**2단계 — 만족해야 할 불변식을 확인한다.**
랩 3절에 세 줄이 있다. 지금은 **코드로 강제하지 않는다.** Lab 1.3에서 강제한다.
지금은 한국어로 다시 써 보는 것까지만 한다.

```
1) 논리적으로 같은 데이터는 →

2) 직렬화 결과는 삽입 순서에 →

3) 인코딩은 →
```

**3단계 — 가장 단순한 것부터 채운다.**
랩 3절의 표는 7행이다. **한 행씩** 채워라. 위에서부터 내려가면 된다.
한 행 = 실험 하나 = `print` 두 줄이다.

**4단계 — 한 행 채울 때마다 돌린다.**

```
uv run python labs/hash_play.py
```

표를 다 만들고 한 번에 돌리면 어느 행이 이상한지 못 찾는다.

**5단계 — 예상과 다르면 멈춘다.**
"같을 줄 알았는데 달랐다"가 나오면 그 행이 수확이다. **거기서 왜인지 한 줄 적어라.**
`TypeError`가 나면 → [설정 가이드 — ModuleNotFoundError가 났을 때](../phase-0/설정-가이드.md#modulenotfounderror가-났을-때)와는
다른 문제다. 에러 메시지가 요구하는 것(인코딩)을 그대로 해 주면 된다.

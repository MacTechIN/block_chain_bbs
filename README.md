# block_chain_bbs

> 블록체인을 **눈으로 보면서** 배우기 위해, 작은 블록체인 기반 BBS(게시판)를 맨손으로 만들어 가는 학습 프로젝트.

## 무엇을, 왜

이론으로 읽은 블록체인은 잘 잊힌다. 이 저장소는 그 반대 순서로 간다.
**먼저 취약하게 만들고 → 직접 깨뜨려 보고 → 그 다음에 방어를 도입한다.**
게시판이라는 소재를 고른 이유는 "글이 지워지지 않는다"는 불변성을 화면에서 바로 체감할 수 있기 때문이다.

최종 목표물은 글이 블록에 담기고, PoW로 채굴되고, 여러 노드가 gossip으로 동기화되며,
브라우저 탐색기에서 블록·해시·포크·공격을 실시간으로 볼 수 있는 반응형 웹앱이다.

## 빠른 시작

아직 실행할 것이 없다. Phase 0을 끝내면 이 자리에 아래 명령이 채워진다.

```
uv sync          # 의존성 설치        (Phase 0에서 생김)
uv run pytest    # 테스트             (Phase 0에서 생김)
uv run bbschain  # 노드 실행          (Phase 1~2에서 생김)
```

지금 할 일은 하나다 → [docs/labs/phase-0-setup.md](docs/labs/phase-0-setup.md)

## ⚠️ 경고 — 이 게시판에 올린 글은 삭제할 수 없다

이 프로젝트가 만드는 것은 **불변(append-only) 게시판**이다. 설계상 삭제 기능이 없다.

- 한번 블록에 담겨 채굴된 글은 **수정도 삭제도 되지 않는다.** 뒤에 정정 글을 붙일 수 있을 뿐이다.
- Phase 5 이후에는 글이 다른 노드로 전파되므로, 내 노드의 파일을 지워도 **남의 노드에는 그대로 남는다.**
- Phase 7에서 공개 배포하면 인터넷 누구나 읽을 수 있고, Sepolia 앵커링 이후에는 그 흔적이 공개 이더리움에도 남는다.
- 따라서 **실명, 연락처, 비밀번호, 개인정보, 남에게 보이면 곤란한 내용을 절대 쓰지 마라.** 테스트 글만 쓴다.
- 같은 이유로 개인키 파일(`*.key`, `keystore/`)은 `.gitignore`에 선등록되어 있다. 커밋 전에 항상 확인하라.
